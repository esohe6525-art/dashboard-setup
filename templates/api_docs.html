Task Tracker API Documentation

A small REST API for managing tasks with Flask.

GET /tasks

Retrieve all tasks.

Response:

[{"id": 1, "title": "Buy groceries", "description": "Eggs", "completed": false, "created_at": "..."}]

GET /tasks/<id>

Retrieve one task by ID.

Response:

{"id": 1, "title": "Buy groceries", "description": "Eggs", "completed": false, "created_at": "..."}

POST /tasks

Create a new task.

Body (JSON):

{"title": "Buy groceries", "description": "Milk, eggs", "completed": false}

Response:

{"id": 1, "title": "Buy groceries", "description": "Milk, eggs", "completed": false, "created_at": "..."}

PUT /tasks/<id>

Update an existing task.

Body (JSON):

{"title": "Buy groceries", "completed": true}

DELETE /tasks/<id>

Delete a task by ID.

Response:

{"message": "Task deleted successfully."}
